# 2D Shooter — шутер с видом сверху на Pygame

Аркадный 2D-шутер с видом сверху: волны врагов, боссы, подбираемые бафы,
постоянные улучшения и несколько вариантов фона карты. Вся графика рисуется
примитивами, звуки синтезируются программно — внешние ассеты не нужны.

## Требования

- Python 3.9+ (проверено на 3.11)
- Pygame 2.x (проверено на 2.6.1)

## Установка

```bash
pip install pygame
```

Если в системе не настроен `python` в PATH (типично для Windows), используйте
лаунчер `py`.

## Запуск

```bash
py main.py
```

или

```bash
python main.py
```

## Управление

| Клавиши / мышь | Действие |
|---|---|
| `W` `A` `S` `D` | Движение |
| Мышь | Прицеливание |
| ЛКМ (можно зажать) | Стрельба |
| `ESC` или `P` | Пауза / продолжить |
| `SPACE` | Начать игру / продолжить (на паузе) |
| `R` | Начать заново (на паузе и на экране проигрыша) |
| `Q` | Выйти в главное меню (на паузе) |
| `S` | Настройки (выбор фона карты) в главном меню |
| `1` `2` `3` | Выбор улучшения после босса; в настройках — выбор фона |

## Игровой процесс

- **Волны.** Враги появляются волнами по 12 секунд. С каждой волной у них растёт
  запас здоровья и скорость, а спавн становится чаще.
- **Враги.**
  - зелёный «basic» — обычный преследователь;
  - жёлтый «fast» — быстрый и хрупкий (со 2-й волны);
  - красный «tank» — медленный, но живучий (с 3-й волны);
  - фиолетовый **босс** — каждые 5 волн, много здоровья и высокий урон.
- **Здоровье.** У игрока 100 HP, после получения урона действует короткая
  неуязвимость. Контакт с врагом отнимает здоровье.
- **Счёт и убийства.** За каждого врага начисляются очки; статистика видна в HUD.

## Бафы на карте

На поле периодически появляются подбираемые предметы (не более трёх
одновременно, исчезают через 15–20 секунд):

| Баф | Обозначение | Эффект |
|---|---|---|
| Аптечка | `+` | Мгновенно +35 HP |
| Скорострельность | `F` | Перезарядка ×0,5 на 10 секунд |
| Ускорение | `S` | Скорость передвижения ×1,5 на 10 секунд |
| Урон | `D` | Урон выстрела ×2 на 10 секунд |
| Щит | `Щ` | Полный иммунитет к урону 7 секунд |

Активные эффекты и их оставшееся время отображаются в HUD под полосой здоровья.

## Улучшения после босса

После убийства босса игра ставит паузу и предлагает **выбрать одно из трёх**
постоянных улучшений (клавиши `1`/`2`/`3` или клик по карточке).
Улучшения слабее бафов, но действуют до конца забега и складываются.

Обычные:

- **+15 к здоровью** — максимум HP +15 и мгновенное лечение на 15;
- **Урон +10%**;
- **Скорострельность +7%**;
- **Пробитие +1** — пуля пробивает насквозь на одного врага больше (максимум +3);
- **Скорость +8%**.

Редкие (шанс 18% на каждый слот, отмечены золотой рамкой и бейджем «РЕДКОЕ»):

- **Регенерация** — +1 HP каждую секунду;
- **Вампиризм** — +2 HP за каждое убийство.

### Как работает пробитие

- Без улучшения пуля наносит урон первому врагу и исчезает.
- «Пробитие +1»: пуля наносит **тот же урон** первому врагу, пролетает сквозь
  него и исчезает только на втором.
- «Пробитие +2»: проходит сквозь двух врагов и гаснет на третьем.

Каждый враг получает урон от одной пули ровно один раз. Для надёжности
используются swept-коллизии по траектории полёта пули, поэтому попадания не
теряются даже при низком FPS.

## Настройки фона карты

В главном меню нажмите `S`. Доступны три варианта фона с живым превью:

- **Сетка** — тёмное поле с сеткой (классический вариант);
- **Асфальт** — серое асфальтовое поле с редкими деталями: заплатки, трещины,
  масляные пятна, люк и выцветшая разметка;
- **Поляна** — трава с редкими цветами, кустиками, камнями, парой кустов и
  вытоптанной тропинкой.

Переключение: `←`/`→` (или `A`/`D`), прямой выбор клавишами `1`/`2`/`3`,
выход — `ESC`/`S`. Выбор сохраняется и применяется при следующих запусках.

## Рекорды

Лучший счёт и лучшее число убийств сохраняются в файл `highscore.json` и
переживают закрытие игры. Рекорд отображается:

- в главном меню;
- в HUD во время игры (по центру сверху);
- на экране проигрыша (с бейджем «НОВЫЙ РЕКОРД!» при побитии).

## Сохраняемые файлы

| Файл | Назначение |
|---|---|
| `highscore.json` | Лучший счёт и убийства |
| `settings.json` | Выбранный фон карты |

Файлы создаются автоматически при первом сохранении. Их можно удалить —
игра начнёт с нулевых рекордов и фона «Сетка».

## Советы

- Не стойте на месте: враги стекаются к игроку, и толпа быстро снимает HP.
- Держите дистанцию и стреляйте в направлении скоплений — пули с пробитием
  эффективны против «паровозиков» врагов.
- Баф щита удобно подбирать перед волной с боссом.
- Аптечку стоит оставлять на карте, если HP ещё высокое: она исчезнет через
  20 секунд, но может спасти в критический момент.
